> *"Quality is never an accident; it is always the result of intelligent effort."*

I'm **Rupa**, a passionate **Software Quality Assurance (SQA) Engineer** at **NextPage Technology Ltd.**, dedicated to delivering bug-free, high-performance software through rigorous testing strategies and automation.

- 🔍 Specialized in **Manual, Automation & API Testing**
- 🛠️ Experienced with end-to-end **CI/CD pipeline** workflows
- 📱 Skilled in **Mobile & Web** application testing
- 🐛 Proactive in **bug tracking**, reporting, and resolution
- 🌱 Continuously learning and evolving with the QA landscape
- 🤝 Open to **collaborating** on testing frameworks & open-source QA projects
